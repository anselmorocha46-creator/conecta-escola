Conecta Escola

Sistema de Gestão de Serviços Digitais Escolares

1. Apresentação

O Conecta Escola é um sistema desenvolvido com o objetivo de auxiliar na organização e no gerenciamento dos recursos tecnológicos de uma instituição de ensino.

2. Objetivo

Facilitar o gerenciamento de usuários, equipamentos, serviços de internet e solicitações de suporte técnico no ambiente escolar.

3. Funcionalidades previstas

- Cadastro e gerenciamento de usuários.
- Controle de acesso por perfil.
- Autenticação de usuários.
- Gerenciamento de registros.
- Consulta e pesquisa de informações.
- Solicitações de suporte técnico.
- Histórico de operações.

4. Requisitos

O projeto segue os requisitos funcionais, não funcionais e regras de negócio definidos na documentação de requisitos.

5. Público-alvo

Administradores, professores e funcionários da instituição de ensino.

6. Desenvolvimento

Projeto acadêmico desenvolvido como atividade do curso de Análise e Desenvolvimento de Sistemas.

7. Status

Em desenvolvimento.

8. Equipe

Projeto desenvolvido pelos integrantes do grupo acadêmico.# conecta-escola
